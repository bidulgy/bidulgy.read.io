# Rhythm Soul — music prototype

`assets/sans.mp3` is the user-provided track used by this prototype.

## Play
Open `index.html` in a modern browser. Press START, then press any keyboard key at the exact moment a projectile reaches the soul.

- PERFECT / GOOD / BAD / MISS timing
- Combo and score
- Projectile timing chart generated from the uploaded track's detected onsets
- R: restart
- M: pause/resume music

The visual assets in this prototype are original placeholder graphics; no UNDERTALE/Toby Fox artwork is bundled.
